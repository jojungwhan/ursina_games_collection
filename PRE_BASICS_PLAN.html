    Overview

    Create a new pre_basics folder with 6 separate lesson files that teach Python fundamentals to complete beginners using turtle graphics. These lessons will come before one_basics in the navigation structure.

    Lesson-Specific Content (Updated)

    Lesson 1: Turtle Movement and Control

    Key Concepts: - Sequential execution (top to bottom) - Import statements (from turtle import *) - Basic turtle commands: forward(), right(), left(), shape(), done() - Canvas reset: reset() or clear() - taught early to prevent drawing over old messes - Syntax errors (typos, case sensitivity)

    Code Examples: - First greeting program - Drawing 'ㄱ', 'ㄴ', 'ㄷ' shapes - Common syntax errors - Using reset() to clear canvas

    Blockly Blocks: - Turtle setup - Forward/backward movement - Left/right rotation

    📚 깊이 이해하기 (Deep Understanding): - The Stage: The Coordinate System - Cartesian coordinate system explanation - (0, 0) is the center of the screen, not the top-left - X-axis: left (-) to right (+) - Y-axis: bottom (-) to top (+) - Visual diagram showing coordinate plane

    • Direction: Turtle Orientation
    • 0 degrees is East (Right)
    • 90 degrees is North (Up)
    • 180 degrees is West (Left)
    • 270 degrees is South (Down)
    • Diagram showing degrees and directions

    Mermaid Diagram: - Sequential execution flowchart - Coordinate system visualization

    🚑 긴급 점검 (Debug Clinic): - Syntax errors (typos, case sensitivity) - Canvas reset reminders

    Lesson 2: Colors and Variables

    Key Concepts: - Variables as containers - Assignment operator (=) - Using variables to change size/color - bgcolor(), pencolor()

    Code Examples: - Variable for size - Variable for color - Drawing shapes with variables

    Blockly Blocks: - Variable creation - Color blocks

    Mermaid Diagram: - Variable assignment flow

    🚑 긴급 점검 (Debug Clinic): - Variable naming errors - Assignment vs equality confusion

    Lesson 3: Understanding Range

    Key Concepts: - range() function - Zero-based indexing - range(숫자) vs range(시작, 끝) vs range(시작, 끝, 간격) - Off-by-one errors - Using print() to visualize numbers - Visible Output: Console vs Canvas - Console: text output (print()) - Canvas: visual output (turtle drawing) - Understanding the difference

    Code Examples: - for i in range(5): print(i) - showing 0-4 - Even numbers with step - Understanding why 5 doesn't appear - Console output vs canvas output comparison

    Blockly Blocks: - Range blocks - Print blocks

    Interactive Element: - Challenge Quiz: "Predict the last number" - Students predict what range(n) will output before running code

    Mermaid Diagram: - Range generation process - Console vs Canvas distinction

    🚑 긴급 점검 (Debug Clinic): - Off-by-one errors - "Why doesn't 5 appear?" confusion

    Lesson 4: The 'For' Loop

    Key Concepts: - for loop syntax - Colon (:) importance - Indentation (tabs/spaces) - Repeating actions - Drawing patterns (square, star)

    Code Examples: - Turtle stamping (repeating position) - Drawing square with loop - Drawing star (5 repetitions, 144 degrees)

    Blockly Blocks: - Repeat blocks - Nested blocks for loop body

    Mermaid Diagram: - Loop execution flow - Indentation importance visualization

    🚑 긴급 점검 (Debug Clinic): - Indentation errors - Missing colon errors

    Lesson 5: Loop Variable 'i'

    Key Concepts: - Loop variable changes each iteration - Using i in calculations - forward(i) - growing lines - circle(i) - growing circles - goto(i * 50, 0) - positioning - Understanding why first iteration might not move (i=0)

    Code Examples: - Growing circles - Line spacing - Understanding why first iteration might not move (i=0)

    Blockly Blocks: - Loop variable usage - Math operations with loop variable

    📚 깊이 이해하기 (Deep Understanding): - Trace Table (추적표) - Visual table showing loop execution step-by-step - Columns: Loop Step, Value of i, Action, Result - Example: | Loop Step | Value of i | Action | Result | |:---|:---|:---|:---| | 1st run | 0 | forward(0) | No movement (0 pixels) | | 2nd run | 1 | forward(1) | Moves 1 pixel | | 3rd run | 2 | forward(2) | Moves 2 pixels | | 4th run | 3 | forward(3) | Moves 3 pixels |

    Mermaid Diagram: - State Diagram: Show i updating throughout loop - [i=0] --> [Code runs: forward(0)] --> [i becomes 1] --> [Code runs: forward(1)] --> [i becomes 2] --> ... - Visual representation of loop variable evolution

    🚑 긴급 점검 (Debug Clinic): - "Why doesn't it move on first iteration?" (i=0 issue) - Logic errors with loop variables

    Lesson 6: Final Project - Spiral

    Key Concepts: - Combining all concepts - Import, variables, range, for loop, loop variable - Random colors (choice()) - Spiral pattern (incremental forward, slight angle)

    Code Examples: - Complete spiral code - Step-by-step assembly - Experimentation suggestions

    Blockly Blocks: - Complete spiral project - All turtle blocks combined

    Mermaid Diagram: - Complete program flow - Spiral generation process

    🚑 긴급 점검 (Debug Clinic): - Combining concepts troubleshooting - Angle adjustment experimentation
