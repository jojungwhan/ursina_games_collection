    코드 살펴보기

    아래는 첫 번째 거북이 프로그램입니다. 거북이를 움직여서 선을 그려봅시다!

    📂 폴더: pre_basics_and_setup / 📄 파일: turtle_hello.py

    turtle_hello.py
    from turtle import *  # (1)

shape('turtle')  # (2)
forward(100)     # (3)
    1. 거북이 라이브러리의 모든 기능을 가져옵니다. *는 "모든 것"을 의미합니다.
    2. 거북이 모양을 화면에 보이는 거북이 아이콘으로 설정합니다.
    3. 거북이를 앞으로 100 픽셀만큼 이동시킵니다. 이때 선이 그려집니다.

    ⚡ 실행 방법이 기억나지 않나요? (클릭)

    • 터미널 이동: cd .. 후 cd 폴더명
    • 실행: python turtle_hello.py (Tab 키로 자동완성)
    • 종료: 창을 닫거나 Ctrl+C (터미널에서)

    🎮 조작 방법

    거북이 프로그램을 실행하면:

    • 창 닫기: 마우스로 창의 X 버튼 클릭
    • 다시 실행: 프로그램을 다시 실행하면 새 창이 열립니다
    • 캔버스 초기화: 프로그램을 다시 실행하거나 reset() 명령 사용

    💡 코드 이해하기

    이제 코드를 주요 부분별로 분석해봅시다!

    라이브러리 불러오기 (Import Statement)

    위의 코드 (1)번을 보면, from turtle import *는 거북이 라이브러리의 모든 기능을 가져옵니다.

    핵심 개념: - from turtle: 거북이 라이브러리에서 기능을 가져옵니다 - import *: *는 "모든 것"을 의미합니다. 모든 기능을 한 번에 가져옵니다 - 이 줄을 실행하면 forward(), right(), left() 등을 바로 사용할 수 있게 됩니다

    마치 도서관에서 책을 빌려오는 것과 같아요! 📚

    거북이 모양 설정 (Shape)

    코드 (2)번에서 shape('turtle')는 거북이 모양을 설정합니다.

    shape('turtle')

    설명: - shape(): 거북이의 모양을 바꾸는 함수입니다 - 'turtle': 거북이 아이콘 모양으로 설정합니다 - 다른 옵션: 'arrow', 'circle', 'square', 'triangle' 등

    앞으로 이동하기 (Forward)

    코드 (3)번에서 forward(100)는 거북이를 앞으로 이동시킵니다.

    forward(100)

    설명: - forward(): 거북이를 앞으로 이동시키는 함수입니다 - 100: 이동할 거리(픽셀)입니다 - 거북이가 이동하면서 선을 그립니다

    📏 픽셀이란?

    픽셀은 화면의 가장 작은 점입니다. forward(100)은 100개의 점만큼 이동한다는 뜻입니다.

    📚 깊이 이해하기

    코드를 실행해봤으니, 이제 중요한 개념들을 더 깊이 이해해봅시다!

    순차 실행 (Sequential Execution)

    파이썬 코드는 위에서 아래로 한 줄씩 실행됩니다. 마치 요리 레시피를 순서대로 따라하는 것과 같아요!

    from turtle import *  # 1번째: 라이브러리 불러오기
shape('turtle')       # 2번째: 거북이 모양 설정
forward(100)          # 3번째: 앞으로 이동

    코드는 순서대로 실행됩니다: 1. 먼저 라이브러리를 불러옵니다 2. 그 다음 거북이 모양을 설정합니다 3. 그 다음 앞으로 이동합니다

    📖 순서가 중요해요!

    코드의 순서를 바꾸면 결과가 달라질 수 있습니다. 예를 들어 shape('turtle')를 forward(100) 다음에 실행하면, 이동한 후에 모양이 바뀝니다!

    좌표계 이해하기 (The Stage: The Coordinate System)

    거북이가 그리는 화면은 좌표계를 사용합니다. 수학 시간에 배운 x축과 y축과 비슷해요!

    중요한 개념: - (0, 0)은 화면의 중앙입니다 (왼쪽 위가 아닙니다!) - X축: 왼쪽(-)에서 오른쪽(+)으로 - Y축: 아래(-)에서 위(+)로 - 거북이는 처음에 화면 중앙 (0, 0)에 있습니다

    🎯 좌표 이해하기

    • goto(0, 0): 화면 중앙으로 이동
    • goto(100, 0): 중앙에서 오른쪽으로 100 이동
    • goto(0, 100): 중앙에서 위로 100 이동
    • goto(-100, 0): 중앙에서 왼쪽으로 100 이동

    방향 이해하기 (Direction: Turtle Orientation)

    거북이는 각도를 사용하여 방향을 정합니다.

    기본 방향: - 0도 (또는 360도): 동쪽(오른쪽) → - 90도: 북쪽(위쪽) ↑ - 180도: 서쪽(왼쪽) ← - 270도 (또는 -90도): 남쪽(아래쪽) ↓

    회전 명령어: - right(90): 오른쪽으로 90도 회전 (시계 방향) - left(90): 왼쪽으로 90도 회전 (반시계 방향)

    회전 예제

    from turtle import *
forward(100)   # 오른쪽으로 100 이동
right(90)      # 오른쪽으로 90도 회전 (아래쪽을 향함)
forward(100)   # 아래쪽으로 100 이동

    거북이 라이브러리를 불러오는 올바른 코드는 무엇인가요?

    **정답: A) from turtle import ***

    from turtle import *가 올바른 형식입니다.

    코드에서 확인해보세요: 

    from turtle import *  # ✅ 올바른 코드

    퀴즈 2: 앞으로 이동하기

    퀴즈: 앞으로 이동하기
    거북이를 앞으로 이동시키는 함수 이름은 무엇인가요?
    힌트: ???(100) - 거북이를 100 픽셀 앞으로 이동시킵니다.
    정답 보기

    정답: forward

    코드에서 확인해보세요: 

    forward(100)  # 거북이를 100 픽셀 앞으로 이동

    거북이 기본 명령어 복습:

    거북이를 움직이는 기본 명령어들을 배워봅시다.

    • `from turtle import ` - 거북이 라이브러리를 불러옵니다
    • `shape()` - 거북이 모양으로 설정합니다
    • `forward()` - 거북이를 앞으로 100 픽셀 이동시킵니다

    🚑 긴급 점검 (Debug Clinic)

    거북이를 처음 다룰 때 자주 겪는 문제들과 해결 방법입니다.

    오류 1: 이름 오류 (NameError)

    # ❌ 잘못된 코드
foward(100)  # r을 빼먹음!

    증상: NameError: name 'foward' is not defined
    원인: forward를 foward로 잘못 입력했습니다
    해결: 철자를 정확히 forward로 입력하세요

    # ✅ 올바른 코드
forward(100)  # 올바른 철자!

    오류 2: 대소문자 오류

    # ❌ 잘못된 코드
Forward(100)  # 대문자 F 사용!

    증상: NameError: name 'Forward' is not defined
    원인: 파이썬은 대소문자를 엄격하게 구분합니다. Forward와 forward는 다릅니다
    해결: 모두 소문자로 forward(100)을 사용하세요

    # ✅ 올바른 코드
forward(100)  # 소문자 사용!

    오류 3: 따옴표 누락

    # ❌ 잘못된 코드
shape(turtle)  # 따옴표 없음!

    증상: NameError: name 'turtle' is not defined
    원인: 문자열 값에는 따옴표가 필요합니다
    해결: 'turtle'처럼 따옴표로 감싸세요

    # ✅ 올바른 코드
shape('turtle')  # 따옴표 추가!

    오류 4: 캔버스 초기화

    증상: 이전 그림 위에 새로운 그림이 겹쳐 그려집니다
    해결: 프로그램 시작 부분에 reset() 또는 clear() 추가

    # ✅ 캔버스 초기화
from turtle import *
reset()  # 또는 clear() - 화면 지우기
shape('turtle')
forward(100)

    🧹 캔버스 정리하기

    • reset(): 거북이 위치와 방향도 초기화하고 화면을 지웁니다
    • clear(): 화면만 지우고 거북이 위치는 유지합니다
