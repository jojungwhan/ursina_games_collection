    🗺️ 단계구분도란?

    단계구분도(Choropleth Map)는 지역별 데이터 값을 색상의 농도로 표현하는 지도입니다.

    활용 예시

    • 📊 인구 밀도 지도
    • 💰 지역별 소득 수준
    • 🏥 코로나 확진자 현황
    • 🗳️ 선거 결과 지도
    • 🌡️ 기온/강수량 분포

    🎨 색상 스케일 만들기

    데이터 값에 따라 색상을 반환하는 함수를 만듭니다:

    def get_color(value):
    """값에 따른 색상 반환 함수"""
    if value > 1000: return '#800026'  # 가장 진한 색

    if value > 200:  return '#E31A1C'
    if value > 100:  return '#FC4E2A'
    if value > 50:   return '#FD8D3C'
    if value > 20:   return '#FEB24C'
    if value > 10:   return '#FED976'
    return '#FFEDA0'  # 가장 연한 색

    📊 범례 (Legend) 추가하기

    고급 기능

    범례(Legend)와 커스텀 컨트롤은 JavaScript 전용 기능입니다. Python에서는 별도의 시각화 라이브러리(matplotlib 등)를 사용하거나, HTML 출력 시 별도로 범례를 추가해야 합니다.

    범례는 색상이 무엇을 의미하는지 알려줍니다. Python에서는 데이터와 함께 색상 정보를 설명하는 방식으로 대체할 수 있습니다:

    🎨 다양한 색상 스케일

    순차적 (Sequential) - 단일 색상 계열

    낮은 값에서 높은 값으로 농도가 증가:

    def get_blue_scale(d):
    """파란색 계열 색상 스케일"""
    if d > 90: return '#08306b'
    if d > 70: return '#08519c'
    if d > 50: return '#2171b5'
    if d > 30: return '#4292c6'
    if d > 10: return '#6baed6'
    return '#c6dbef'

    발산형 (Diverging) - 중앙값 기준 양방향

    중앙값을 기준으로 양쪽으로 다른 색상:

    def get_diverging_scale(d):
    """빨강-흰색-파랑 (음수/양수, 감소/증가)"""
    if d > 20:  return '#d73027'  # 강한 증가 (빨강)
    if d > 10:  return '#fc8d59'
    if d > 0:   return '#fee08b'
    if d > -10: return '#d9ef8b'
    if d > -20: return '#91cf60'
    return '#1a9850'  # 강한 감소 (녹색)

def get_change_color(d):
    """발산형 색상 (인구 변화율: 음수=감소, 양수=증가)"""
    if d > 2:   return '#1a9850'  # 강한 증가 (녹색)
    if d > 1:   return '#91cf60'
    if d > 0:   return '#d9ef8b'
    if d > -1:  return '#fee08b'
    if d > -2:  return '#fc8d59'
    return '#d73027'  # 강한 감소 (빨강)

    📝 정리 퀴즈

    Q1. 단계구분도(Choropleth Map)란?

    지역별 데이터 값을 색상의 농도로 표현하는 주제도입니다. 값이 높을수록 진한 색, 낮을수록 연한 색을 사용합니다.

    Q2. 발산형(Diverging) 색상 스케일은 언제 사용하나요?

    중앙값이나 기준값을 중심으로 양쪽 방향의 변화를 표현할 때 사용합니다. 예: 인구 증감률, 온도 변화, 찬반 비율 등

    Q3. Python에서 단계구분도를 만드는 방법은?

    add_polygon() 메서드를 사용하여 각 지역별로 폴리곤을 추가하고, 색상 함수로 fill_color를 지정합니다:
