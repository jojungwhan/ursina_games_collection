    🎯 학습 목표

    이 강의를 마치면 다음을 할 수 있어요:

    • ○ import가 무엇인지 이해한다
    • ○ 왜 라이브러리를 불러와야 하는지 이해한다
    • ○ import turtle 문법을 사용할 수 있다

    핵심 개념

    import란?

    import는 "도구를 가져오다"라는 뜻입니다. 거북이 기능은 파이썬에 기본으로 없어요. 가져와야 사용할 수 있습니다!

    import turtle  # 거북이 도구 가져오기!

    🍳 비유: 요리와 코딩

    요리를 하려면 먼저 냉장고에서 재료를 꺼내야 하죠? 코딩도 마찬가지로, 먼저 필요한 도구를 가져와야 합니다!

    • 냉장고 = 파이썬 라이브러리 저장소
    • 재료 꺼내기 = import 명령어
    • 거북이 재료 = turtle 라이브러리

    import의 흐름

    flowchart LR
    A["import turtle"] --> B["turtle.Turtle()"]
    B --> C["거북이 명령들"]

    순서 코드 설명
    1️⃣ import turtle 도구 가져오기
    2️⃣ turtle.Turtle() 거북이 만들기
    3️⃣ 명령들 forward, right 등

      4.

    📝 import는 항상 맨 위에!
    

    import 문은 항상 코드의 맨 첫 줄에 작성해야 합니다.
도구를 꺼내지 않고는 사용할 수 없으니까요!
    

    

    

    🎯 퀴즈
    

    퀴즈 1: import의 역할
    

    
    
    퀴즈: import의 역할
    
    
    
        `import turtle`은 무엇을 하나요?
    
    
    
    
        
        
        
    
    
    
    

    


    
정답 보기

    정답: A) 거북이 도구를 가져온다
    

    import는 "가져오다"라는 뜻입니다. import turtle은 파이썬에게
"거북이 도구를 사용할 거야!"라고 알려주는 것입니다.
    

    import turtle  # 거북이 도구를 가져온다!

    

    이 한 줄이 없으면 turtle.Turtle() 같은 명령을 사용할 수 없습니다.
    

    

    

    import 문법 연습
    

    거북이 도구를 가져오려면:
    

    import turtle

    

      

    • import = 가져오다 (라이브러리를 불러오는 키워드)
      • 

    • turtle = 거북이 그래픽 라이브러리 이름
      • 

    

    

    

    🔧 디버그 클리닉
    

    문제: NameError가 발생해요!
    

    

    ❌ 잘못된 코드
    

    t = turtle.Turtle()  # turtle이 뭐야?

    
오류 메시지: NameError: name 'turtle' is not defined
    

    원인: import turtle을 안 썼어요
    

    

    

    ✅ 올바른 코드
    

    import turtle        # 먼저 가져오기!
t = turtle.Turtle()

    
해결: 프로그램 맨 위에 import turtle 추가!
    

    

    

    직접 코딩해보기
    

    블록으로 배운 내용을 Python 코드로 직접 작성해보세요!
    

    거북이로 ㄱ 모양 그리기
    

    import turtle로 거북이 도구를 가져온 후, ㄱ 모양을 그려보세요.
성공하면: 거북이가 앞으로 갔다가 오른쪽으로 꺾여서 ㄱ 모양을 그립니다!
    

    

    


    
예시 답안

    import turtle

t = turtle.Turtle()
t.shape('turtle')
t.forward(100)
t.right(90)
t.forward(100)

    

    결과: 거북이가 ㄱ 모양을 그립니다!
