    핵심 개념

    자료형이란?

    자료형(Data Type)은 데이터의 종류입니다. 파이썬은 데이터가 숫자인지, 글자인지, 참/거짓인지 구분합니다.

    123        # 정수 (int)
3.14       # 실수 (float)
"안녕"     # 문자열 (str)
True       # 불리언 (bool)

    📦 비유: 상자의 종류

    마트에서 물건을 담을 때, 종류에 맞는 상자를 사용하죠?

    • 과일 상자 → 과일만 담음 (정수 상자에는 정수만!)
    • 냉동 상자 → 냉동식품만 담음 (문자열 상자에는 글자만!)

    파이썬도 데이터 종류에 맞는 "상자"를 사용합니다.

    4가지 기본 자료형

    1. 정수 (int) - Integer

    소수점이 없는 숫자입니다.

    age = 13
score = 100
temperature = -5

    2. 실수 (float) - Floating Point

    소수점이 있는 숫자입니다.

    pi = 3.14
height = 165.5
price = 9.99

    3. 문자열 (str) - String

    글자, 단어, 문장입니다. 따옴표로 감쌉니다.

    name = "철수"
greeting = '안녕하세요'
message = "123"   # 숫자처럼 보여도 따옴표 안에 있으면 문자열!

    4. 불리언 (bool) - Boolean

    참(True) 또는 거짓(False) 두 가지 값만 있습니다.

    is_student = True
is_adult = False

    자료형 확인: type()

    type() 함수로 데이터의 자료형을 확인할 수 있습니다.

    print(type(123))       # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("Hello"))   # <class 'str'>
print(type(True))      # <class 'bool'>

    자료형 변환 (형변환)

    자료형을 다른 자료형으로 바꿀 수 있습니다.

    # 문자열 → 정수
num = int("123")       # 123

# 정수 → 문자열
text = str(456)        # "456"

# 문자열 → 실수
price = float("9.99")  # 9.99

# 정수 → 불리언
result = bool(1)       # True (0이 아니면 True)
result = bool(0)       # False

    자료형 영어 예시 설명
    정수 int 13, -5, 0 소수점 없는 숫자
    실수 float 3.14, 0.5 소수점 있는 숫자
    문자열 str "안녕", 'Hi' 글자, 단어, 문장
    불리언 bool True, False 참 또는 거짓

    예제 코드

    # 다양한 자료형 변수 만들기
name = "영희"          # str (문자열)
age = 14               # int (정수)
height = 158.5         # float (실수)
is_student = True      # bool (불리언)

# 자료형 확인하기
print(f"name의 자료형: {type(name)}")
print(f"age의 자료형: {type(age)}")
print(f"height의 자료형: {type(height)}")
print(f"is_student의 자료형: {type(is_student)}")

# 형변환 예시
user_input = "25"                     # 문자열 "25"
user_age = int(user_input)            # 정수 25로 변환
print(f"입력값 + 5 = {user_age + 5}") # 30

    결과: 

    name의 자료형: <class 'str'>
age의 자료형: <class 'int'>
height의 자료형: <class 'float'>
is_student의 자료형: <class 'bool'>
입력값 + 5 = 30

    문제 1: TypeError - 문자열과 숫자 연산

    ❌ 잘못된 코드

    age = "13"
print(age + 5)  # TypeError!
    원인: "13"은 문자열이라 숫자 5와 더할 수 없어요

    ✅ 올바른 코드

    age = "13"
print(int(age) + 5)  # 18 출력
    해결: 형변환을 사용하세요!

    문제 2: ValueError - 잘못된 형변환

    ❌ 잘못된 코드

    int("hello")  # ValueError!
    원인: "hello"는 숫자가 아니라서 int()로 변환 불가

    ✅ 올바른 코드

    int("123")    # 가능 (숫자 형태의 문자열)
float("3.14") # 가능 (소수 형태의 문자열)
    주의: 형변환은 변환 가능한 값에만 사용하세요!

    문자열 "50"과 "30"을 정수로 변환하고 더해보세요. 형변환 없이는 덧셈이 안 됩니다!

    예시 답안 
    # 문자열 숫자가 주어졌어요
text1 = "50"
text2 = "30"

# 이대로 더하면? (문자열 연결!)
print(text1 + text2)  # "5030"이 나와요

# int()로 형변환해서 진짜 덧셈을 해보세요
result = int(text1) + int(text2)
print(result)  # 80

    결과: 

    5030
80

    🧩 핵심 요약

    이번 강의에서 배운 내용:

    • 자료형은 데이터의 종류입니다
    • 파이썬의 4가지 기본 자료형:
      • int (정수): 소수점 없는 숫자
      • float (실수): 소수점 있는 숫자
      • str (문자열): 글자, 단어, 문장
      • bool (불리언): True 또는 False
    • type() 함수로 자료형을 확인할 수 있습니다
    • int(), str(), float(), bool()로 자료형을 변환합니다
