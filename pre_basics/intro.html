    시작: Python과 Turtle 소개

    Python Basics 과정에 오신 것을 환영합니다!

    이 과정에서 배우는 것

    이 과정에서는 Python 프로그래밍의 기초를 Turtle 그래픽을 통해 결과물을 보면서 비쥬얼하게 배웁니다.

    Turtle은 화면에서 거북이를 움직여 그림을 그리는 도구입니다. 코드를 작성하면 거북이가 명령을 따라 움직이며, 여러분이 원하는 모양을 그릴 수 있습니다!

    무엇을 만들 수 있나요?

    이 과정을 마치면 다음과 같은 것들을 만들 수 있습니다:

    • 다양한 도형 (사각형, 삼각형, 별)
    • 한글 자음 모양 (ㄱ, ㄴ, ㄷ)
    • 다채로운 색상의 그림
    • 반복 패턴과 나선형 예술 작품

    배우게 될 개념

    단원 주제 배우는 것

    6 🌌 나만의 우주 만들기 나선형 예술
