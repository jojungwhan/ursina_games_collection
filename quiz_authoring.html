    Cloze Quiz Authoring Guide

    이 가이드는 MkDocs 문서에 fill-in-the-blank (빈칸 채우기) 퀴즈를 추가하는 방법을 설명합니다.

    개요

    Cloze 퀴즈는 학생들이 텍스트의 빈칸을 채워서 학습 내용을 확인할 수 있는 인터랙티브한 퀴즈입니다.

    기본 문법

    퀴즈 블록

    퀴즈는 cloze-quiz 블록으로 감싸야 합니다:

    ::: cloze-quiz id="quiz-01"
문장: Entity는 Ursina에서 모든 물체를 의미하는 {{blank:Entity|case=insensitive}} 입니다.
:::

    빈칸 문법

    빈칸은 {{blank:ANSWER}} 형식으로 작성합니다:

    {{blank:Entity}}

    고급 옵션

    여러 정답 허용

    쉼표로 구분하여 여러 정답을 허용할 수 있습니다:

    {{blank:Entity,entity,ENTITY}}

    대소문자 구분

    기본적으로 대소문자를 구분합니다. 대소문자를 무시하려면:

    {{blank:Entity|case=insensitive}}

    공백 자동 제거

    기본적으로 입력값의 앞뒤 공백을 자동으로 제거합니다. 공백을 유지하려면:

    {{blank:Entity|trim=false}}

    힌트 추가

    힌트를 제공할 수 있습니다:

    {{blank:Entity|hint=Ursina의 기본 클래스입니다}}

    힌트 버튼이 표시되며, 클릭하면 힌트가 나타납니다.

    정규식 패턴

    정규식을 사용하여 답을 검증할 수 있습니다:

    {{blank:Entity|pattern=regex:^Ent.*$}}

    regex: 접두사는 선택사항입니다.

    완전한 예제

    예제 1: 기본 퀴즈

    ::: cloze-quiz id="vars-entity-01"
문장: Entity는 Ursina에서 모든 물체를 의미하는 {{blank:Entity|case=insensitive}} 입니다.
코드: `Entity(model={{blank:cube}}, color={{blank:color.azure}}, scale={{blank:2}})`
:::

    예제 2: 힌트가 있는 퀴즈

    ::: cloze-quiz id="functions-01"
함수는 {{blank:def|hint=함수를 정의하는 키워드}} 키워드로 정의합니다.
함수 이름 뒤에는 {{blank:():|hint=함수 인자를 받는 부분}} 이 옵니다.
:::

    예제 3: 여러 정답 허용

    ::: cloze-quiz id="colors-01"
색상을 지정할 때는 {{blank:color.red,red,Color.red|case=insensitive}} 를 사용할 수 있습니다.
:::

    예제 4: 정규식 패턴

    ::: cloze-quiz id="naming-01"
변수 이름은 {{blank:변수명|pattern=^[a-z_][a-z0-9_]*$|hint=소문자로 시작하는 이름}} 형식이어야 합니다.
:::

    예제 5: 복잡한 예제

    ::: cloze-quiz id="complete-example"
Entity를 만들 때:
- `model={{blank:cube,sphere,plane|hint=3D 모델의 종류}}` 로 모양을 지정합니다.
- `color={{blank:color.red,color.blue,color.green|case=insensitive|hint=색상 속성}}` 로 색상을 지정합니다.
- `scale={{blank:1,2,3|hint=크기 배율}}` 로 크기를 조절합니다.

코드 예시:
```python
my_entity = Entity(
    model={{blank:cube}},
    color={{blank:color.azure}},
    position={{blank:(0,0,0)}}
)
    ::: 
    ## 퀴즈 동작

### 사용자 인터페이스

각 퀴즈 블록에는 다음이 포함됩니다:

1. **빈칸 입력 필드**: 사용자가 답을 입력하는 곳
2. **힌트 버튼** (옵션): 힌트가 있는 경우 표시
3. **정답 확인 버튼**: 모든 답을 확인
4. **다시 하기 버튼**: 퀴즈를 초기화
5. **점수 표시**: 정답 개수 표시 (예: 3/4)
6. **저장된 답안 지우기 버튼**: localStorage에 저장된 답을 삭제

### 키보드 단축키

- **Enter**: 정답 확인 (입력 필드에서)
- **Escape**: 퀴즈 초기화 (입력 필드에서)

### 자동 저장

사용자가 입력한 답은 자동으로 localStorage에 저장되어 페이지를 새로고침해도 유지됩니다.

## HTML 구조

퀴즈는 다음과 같은 HTML 구조로 변환됩니다:

```html
<div class="cloze-quiz" data-quiz-id="vars-entity-01">
  <p>
    문장: Entity는 Ursina에서 모든 물체를 의미하는 
    <input class="cloze-blank" 
           data-answers="Entity" 
           data-case="insensitive" 
           type="text">
    입니다.
  </p>
  <div class="cloze-quiz-controls">
    <div class="cloze-quiz-buttons">
      <button class="cloze-btn-check">정답 확인</button>
      <button class="cloze-btn-reset">다시 하기</button>
    </div>
    <div class="cloze-quiz-score"></div>
    <button class="cloze-btn-clear-saved">저장된 답안 지우기</button>
  </div>
</div>

    주의사항

    코드 블록 내의 빈칸

    코드 블록 (``) 내부의` 토큰은 }변환되지 않습니다. 퀴즈 블록 내부의 일반 텍스트에만 빈칸을 사용하세요.

    퀴즈 ID

    각 퀴즈는 고유한 id를 가져야 합니다. 같은 페이지에 여러 퀴즈가 있어도 각각 다른 ID를 사용하세요.

    마크다운 지원

    퀴즈 블록 내부에서는 일반 마크다운 문법을 사용할 수 있습니다: - 굵게, 기울임 - 인라인 코드 - 리스트 - 링크

    스타일링

    퀴즈는 자동으로 스타일이 적용되며, MkDocs Material 테마와 잘 어울립니다.

    • 정답: 초록색 테두리
    • 오답: 빨간색 테두리
    • 기본: 청록색 테두리

    개발 노트

    확장 프로그램 위치

    Markdown 확장 프로그램은 mkdocs_cloze_extension.py에 있으며, MkDocs가 자동으로 로드합니다.

    JavaScript 초기화

    JavaScript는 다음 이벤트에서 초기화됩니다: - DOMContentLoaded - Material 테마의 navigation 이벤트 - Material 테마의 document$ 이벤트 (있는 경우)

    이를 통해 Material의 instant navigation과도 잘 작동합니다.

    localStorage 키 형식

    저장된 답은 다음 형식의 키로 저장됩니다: 

    cloze-quiz-{quiz-id}-{blank-index}

    예: cloze-quiz-vars-entity-01-0

    문제 해결

    퀴즈가 표시되지 않음

    1. mkdocs.yml에 확장 프로그램이 추가되었는지 확인
    2. JavaScript와 CSS 파일이 extra_javascript와 extra_css에 추가되었는지 확인
    3. 브라우저 콘솔에서 오류 확인

    빈칸이 변환되지 않음

    1. 퀴즈 블록이 cloze-quiz로 시작하고 :::로 끝나는지 확인
    2. 빈칸 문법이 {{blank:...}} 형식인지 확인
    3. 코드 블록 내부가 아닌지 확인

    답이 저장되지 않음

    1. 브라우저가 localStorage를 지원하는지 확인
    2. 브라우저 설정에서 쿠키/로컬 스토리지가 허용되어 있는지 확인
