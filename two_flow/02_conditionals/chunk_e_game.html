    핵심 개념

    게임에서 조건문 활용

    게임은 조건문의 집합입니다! 거의 모든 게임 로직이 조건문으로 구현됩니다.

    🎮 게임 로직 = 조건문

    • 체력이 0이면? → 게임 오버!
    • 점수가 100이면? → 승리!
    • 적과 충돌하면? → 데미지!
    • 아이템을 먹으면? → 점수 증가!

    주요 활용 패턴

    # 1. 체력 시스템
if player.hp <= 0:
    print("게임 오버!")
    application.pause()

# 2. 충돌 검사
if player.intersects(enemy):
    player.hp -= 10

# 3. 경계 검사
if player.x > 10:
    player.x = 10  # 경계 밖으로 못 나가게

# 4. 승리 조건
if len(enemies) == 0:
    print("모든 적 처치! 승리!")

    예제 코드

    from ursina import *

app = Ursina()

# 플레이어
player = Entity(model='cube', color=color.blue, position=(0, 0, 0))
player.hp = 100
player.score = 0

# 적
enemy = Entity(model='cube', color=color.red, position=(3, 0, 0))

# 아이템
item = Entity(model='sphere', color=color.gold, position=(-3, 0, 0), scale=0.5)

def update():
    # 이동
    if held_keys['d']:
        player.x += 5 * time.dt
    if held_keys['a']:
        player.x -= 5 * time.dt

    # 충돌 검사 - 적
    if player.intersects(enemy).hit:
        player.hp -= 1
        print(f"HP: {player.hp}")

        # 체력 검사
        if player.hp <= 0:
            print("게임 오버!")

    # 충돌 검사 - 아이템
    if player.intersects(item).hit:
        player.score += 10
        print(f"점수: {player.score}")
        destroy(item)

EditorCamera()
app.run()

    실행 결과

    A/D로 이동하며 적과 충돌하면 체력이 감소하고, 아이템과 충돌하면 점수가 증가합니다!

    퀴즈

    퀴즈: 게임 오버 조건
    플레이어 체력이 0 이하일 때 게임 오버를 표시하는 코드는?
    정답 보기

    정답: A) if player.hp <= 0:

    • <=는 "작거나 같다" 비교 연산자
    • =는 대입 연산자 (오류 발생!)
    • > 0은 살아있을 때 조건
    if player.hp <= 0:
    print("게임 오버!")

    게임 조건문 연습:

    • 체력 검사: if player.hp 0:
    • 충돌 검사: if player. (enemy).hit:
    • 승리 조건: if len(enemies) 0:

    🔧 디버그 클리닉

    문제: intersects()가 작동하지 않아요!

    ❌ collider가 없는 경우

    player = Entity(model='cube')  # collider 없음!
enemy = Entity(model='cube')   # collider 없음!

if player.intersects(enemy):   # 항상 False!
    print("충돌!")
    원인: 충돌 검사를 하려면 collider가 필요해요

    ✅ collider 추가

    player = Entity(model='cube', collider='box')
enemy = Entity(model='cube', collider='box')

if player.intersects(enemy).hit:
    print("충돌!")
    해결: 두 객체 모두 collider를 추가하세요!
