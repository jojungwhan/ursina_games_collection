    복잡한 데이터 처리

    # 학생 성적 데이터
students = [
    {"이름": "김철수", "국어": 85, "수학": 92, "영어": 78},
    {"이름": "이영희", "국어": 90, "수학": 88, "영어": 95},
    {"이름": "박민수", "국어": 78, "수학": 95, "영어": 82}
]

# 각 학생의 평균 계산
print("=== 학생별 평균 ===")
for student in students:
    name = student["이름"]
    avg = (student["국어"] + student["수학"] + student["영어"]) / 3
    print(f"{name}: {avg:.1f}점")

# 과목별 평균 계산
print("\n=== 과목별 평균 ===")
subjects = ["국어", "수학", "영어"]
for subject in subjects:
    total = sum(s[subject] for s in students)
    avg = total / len(students)
    print(f"{subject}: {avg:.1f}점")

    실행 결과

    === 학생별 평균 ===
김철수: 85.0점
이영희: 91.0점
박민수: 85.0점

=== 과목별 평균 ===
국어: 84.3점
수학: 91.7점
영어: 85.0점

    퀴즈: 데이터 변환
    딕셔너리의 모든 키를 리스트로 변환하려면?
    정답 보기

    정답: A) list(dict.keys())

    data = {"사과": 45, "바나나": 30}

keys = list(data.keys())    # ['사과', '바나나']
values = list(data.values()) # [45, 30]

    keys()와 values()를 list()로 감싸면 리스트가 됩니다!
