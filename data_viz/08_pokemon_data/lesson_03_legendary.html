    • ✨ 전설의 포켓몬: 뮤츠, 레쿠자, 디아루가...
    • 🎮 일반 포켓몬: 피카츄, 이상해씨, 파이리...

    70마리 전설 vs 730마리 일반 전체 데이터로 확인해봅시다!

    배경 지식: 전설의 포켓몬

    ✨ 전설의 포켓몬이란?

    게임에서 단 한 마리만 잡을 수 있는 특별한 포켓몬이에요!

    특징 일반 포켓몬 전설의 포켓몬
    출현 자주 만남 매우 희귀
    포획 쉬움 어려움
    스탯 보통 매우 높음
    배틀 자유 일부 제한

    Step 1: 전설 vs 일반 분리하기

    pandas로 전설과 일반 포켓몬을 분리해봅시다!

    pandas 필터링 복습

    # 조건으로 필터링
legendary = df[df['is_legendary'] == 1]
normal = df[df['is_legendary'] == 0]

# 여러 조건
fire_legendary = df[(df['is_legendary'] == 1) & (df['type1'] == 'fire')]

    Step 2: 총합 스탯 비교 - boxplot + stripplot 📊

    seaborn으로 전설과 일반의 base_total(총합 스탯)을 비교해봅시다!

    seaborn 조합 기법

    # 바이올린플롯 + 스트립플롯 = 분포 + 개별 데이터
sns.violinplot(data=df, x='category', y='value', inner=None)
sns.stripplot(data=df, x='category', y='value', alpha=0.4)

# inner=None으로 바이올린 내부를 비우고 점으로 채워요!

    Step 3: 스탯별 상세 비교 - 멀티 barplot 📈

    전설 포켓몬은 어떤 스탯이 특히 높을까요?

    seaborn barplot의 자동 계산

    # seaborn barplot은 자동으로:
# - 평균값 계산
# - 에러바 (95% 신뢰구간) 추가
# - hue로 그룹 비교

sns.barplot(data=df_long, x='stat', y='value', hue='Type')

# 직접 계산할 필요가 없어요!

    Step 4: 600족 찾기 (준전설) - 고급 scatterplot 🔍

    일반 포켓몬 중에서 전설 수준으로 강한 포켓몬을 찾아봅시다!

    seaborn scatterplot의 다양한 옵션

    sns.scatterplot(
    data=df, x='attack', y='sp_attack',
    hue='category',    # 색상으로 카테고리 구분
    style='category',  # 마커 모양으로도 구분
    size='base_total', # 점 크기로 수치 표현
    sizes=(20, 200)    # 크기 범위 설정
)

    600족이란?

    600족 = 총합 스탯이 600인 일반 포켓몬

    • 전설의 포켓몬처럼 강하지만 대회에서 사용 가능!
    • 드래곤 타입이 많아요 (Dragonite, Salamence, Garchomp...)
    • "준전설(Pseudo-Legendary)"이라고도 불려요

    Step 5: 세대별 전설 포켓몬 분석 - countplot + barplot

    각 세대의 전설 포켓몬은 어떻게 다를까요?

    seaborn countplot vs barplot

    # countplot: 개수를 자동으로 계산
sns.countplot(data=df, x='generation')

# barplot: 평균값을 자동으로 계산
sns.barplot(data=df, x='generation', y='base_total')

# 둘 다 자동 계산이라 코드가 짧아요!
