    미스터리 🔍

    무엇을 조사할까요?

    포켓몬 배틀에서 어떤 전략이 유리할까요?

    • 🗡️ 유리대포: 공격은 높지만 방어가 낮아서 한 방에 쓰러질 수 있음
    • 🛡️ 탱커: 방어는 높지만 공격이 낮아서 상대를 잡는데 오래 걸림

    800마리 포켓몬 전체를 분석해서 확인해봅시다!

    배경 지식: 산점도란?

    📊 산점도 (Scatter Plot)

    두 개의 숫자 데이터 관계를 점으로 표시하는 그래프예요!

    높음 ┃     ⭐        ← 공격 높고 방어도 높음 (만능형)
방   ┃  ●
어   ┃    ●  ●
력   ┃ ●    ●  ●
     ┃●  ●       ⭐ ← 공격 높고 방어 낮음 (유리대포)
낮음 ┗━━━━━━━━━━━━━━━━
       낮음   공격력   높음
    • X축 (가로): 공격력 (Attack)
    • Y축 (세로): 방어력 (Defense)
    • 각 점: 한 마리의 포켓몬

    Step 1: CSV 파일 불러오기 📂

    먼저 pandas와 seaborn을 설치하고 포켓몬 데이터를 불러옵시다!

    seaborn 시작 코드

    import seaborn as sns

# 예쁜 테마 설정 (한 줄이면 끝!)
sns.set_theme(style='whitegrid')

# style 옵션: 'whitegrid', 'darkgrid', 'white', 'dark', 'ticks'

    Step 2: 800마리 전체 산점도 📊

    seaborn으로 모든 포켓몬의 공격력과 방어력을 산점도로 그려봅시다!

    seaborn vs matplotlib 비교

    # matplotlib (복잡함)
plt.scatter(df['attack'], df['defense'], c='blue', s=50, alpha=0.5)

# seaborn (간단함!)
sns.scatterplot(data=df, x='attack', y='defense')

# seaborn 장점: data=df 하나면 컬럼명으로 바로 접근!

    차트 해석 가이드 🗺️

    무엇을 봐야 할까요?

    산점도를 4개 영역으로 나눠서 봐요!

    영역 위치 포켓몬 유형
    🗡️ 유리대포 오른쪽 아래 (공격↑ 방어↓) 한 방에 승부!
    🛡️ 탱커 왼쪽 위 (공격↓ 방어↑) 버티면서 싸움
    ⭐ 만능형 오른쪽 위 (공격↑ 방어↑) 최강 포켓몬!
    😢 약한 포켓몬 왼쪽 아래 (공격↓ 방어↓) 진화가 필요해!

    Step 3: 타입별 색상으로 구분하기 🎨

    seaborn의 hue 파라미터로 타입별로 색상을 자동 구분해봅시다!

    seaborn hue 파라미터

    # hue로 그룹별 색상 자동 구분!
sns.scatterplot(data=df, x='attack', y='defense', hue='type1')

# palette로 색상 팔레트 변경
sns.scatterplot(..., palette='bright')   # 밝은 색
sns.scatterplot(..., palette='deep')     # 진한 색
sns.scatterplot(..., palette='husl')     # 다양한 색

    Step 4: 전설 vs 일반 포켓몬 비교 ✨

    seaborn의 style 파라미터로 전설 포켓몬을 다른 모양으로 표시해봅시다!

    Step 5: jointplot으로 분포까지 한눈에 📊

    seaborn의 jointplot은 산점도 + 히스토그램을 한 번에 보여줘요!

    seaborn jointplot 종류

    # 기본 산점도
sns.jointplot(data=df, x='attack', y='defense', kind='scatter')

# 밀도 등고선
sns.jointplot(data=df, x='attack', y='defense', kind='kde')

# 회귀선 포함
sns.jointplot(data=df, x='attack', y='defense', kind='reg')

# 육각형 밀도
sns.jointplot(data=df, x='attack', y='defense', kind='hex')

    🎯 이번 레슨 요약

    배운 내용

    • [x] pandas + seaborn 설치 및 설정
    • [x] sns.scatterplot() - 기본 산점도
    • [x] hue - 그룹별 색상 구분
    • [x] style - 그룹별 모양 구분
    • [x] sns.jointplot() - 산점도 + 분포 히스토그램

    seaborn 핵심 문법 복습

    import seaborn as sns

# 테마 설정
sns.set_theme(style='whitegrid')

# 기본 산점도
sns.scatterplot(data=df, x='attack', y='defense')

# 그룹별 색상
sns.scatterplot(data=df, x='attack', y='defense', hue='type1')

# 산점도 + 분포
sns.jointplot(data=df, x='attack', y='defense')
