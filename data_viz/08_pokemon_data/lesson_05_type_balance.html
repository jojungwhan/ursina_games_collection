    🎯 학습 목표

    • seaborn countplot으로 타입별 분포 분석하기
    • histplot + kdeplot으로 스탯 분포 이해하기
    • catplot으로 다양한 범주형 데이터 시각화하기
    • pairplot으로 여러 스탯 관계 한눈에 보기

    미스터리 🔍

    무엇을 조사할까요?

    "포켓몬 세계는 균형 잡혀 있을까요?"

    • 모든 타입의 포켓몬이 똑같이 있을까요?
    • 어떤 타입이 가장 많을까요?
    • 게임 밸런스는 어떻게 되어 있을까요?

    800마리 전체 데이터로 확인해봅시다!

    Step 1: 타입별 포켓몬 수 분석 - countplot

    seaborn의 countplot은 자동으로 개수를 세어줍니다!

    seaborn countplot

    # 카테고리별 개수 자동 계산!
sns.countplot(data=df, y='type1', order=type_order)

# order로 정렬 순서 지정
# y=로 수평 막대, x=로 수직 막대

    Step 2: 공격력 분포 - histplot + kdeplot 📊

    seaborn의 histplot은 히스토그램과 밀도 곡선(KDE)을 함께 그립니다!

    = 100])}마리 ({len(df[df[\"attack\"] >= 100])/len(df)*100:.1f}%25)')" data-height="650px" data-mission="대부분의 포켓몬 공격력은 어떤 범위에 있나요?" data-hint="KDE 곡선의 정점(peak)을 확인하세요!">

    histplot vs kdeplot

    # histplot: 히스토그램 + 선택적 KDE
sns.histplot(data=df, x='attack', kde=True)

# kdeplot: 밀도 추정 곡선만
sns.kdeplot(data=df, x='attack', hue='category', fill=True)

# KDE = Kernel Density Estimation
# 데이터의 부드러운 분포 곡선!

    Step 3: 모든 스탯 분포 비교 - FacetGrid 📈

    6개 스탯의 분포를 한눈에 비교해봅시다!

    FacetGrid 활용

    # 여러 서브플롯을 한번에!
g = sns.FacetGrid(df_long, col='stat', col_wrap=3)
g.map_dataframe(sns.histplot, x='value', kde=True)

# col_wrap=3: 한 줄에 3개씩
# map_dataframe: 각 그룹에 함수 적용

    Step 4: 타입별 스탯 비교 - catplot 📊

    각 타입별로 스탯이 어떻게 다른지 boxplot으로 비교해봅시다!

    Step 5: 듀얼 타입 분석 - 히트맵 🔀

    두 가지 타입을 가진 포켓몬의 조합을 히트맵으로 분석해봅시다!

    seaborn heatmap 활용

    # 교차표(crosstab) 생성
matrix = pd.crosstab(df['type1'], df['type2'])

# 히트맵으로 시각화
sns.heatmap(matrix, annot=True, fmt='d', cmap='YlOrRd')

# annot=True: 숫자 표시
# fmt='d': 정수 형식
# cmap: 색상 맵

    Step 6: 스탯 상관관계 - pairplot 🔗

    여러 스탯 간의 관계를 한눈에 봅시다!

    pairplot 읽는 법

    ┌─────────┬─────────┬─────────┐
│ attack  │ att-def │ att-spd │
│  분포   │ 산점도  │ 산점도  │
├─────────┼─────────┼─────────┤
│ def-att │ defense │ def-spd │
│ 산점도  │  분포   │ 산점도  │
├─────────┼─────────┼─────────┤
│ spd-att │ spd-def │  speed  │
│ 산점도  │ 산점도  │  분포   │
└─────────┴─────────┴─────────┘

대각선: 각 스탯의 분포 (KDE)
나머지: 두 스탯의 산점도

    # 개수 세기
sns.countplot(data=df, y='type', order=order)

# 히스토그램 + KDE
sns.histplot(data=df, x='attack', kde=True)

# 밀도 비교
sns.kdeplot(data=df, x='attack', hue='legendary', fill=True)

# 여러 플롯
g = sns.FacetGrid(df, col='stat', col_wrap=3)
g.map_dataframe(sns.histplot, x='value')

# 스탯 관계
sns.pairplot(df, hue='type', diag_kind='kde')
