    배경 지식: 포켓몬 스피드

    ⚡ 스피드(Speed)란?

    포켓몬 배틀에서 누가 먼저 공격하는지 결정해요!

    스피드 높음 → 먼저 공격 → 상대보다 유리!
스피드 낮음 → 나중 공격 → 먼저 맞을 수 있음
    스피드 의미
    150+ 🚀 초고속 (거의 항상 선공)
    100-149 ⚡ 빠름
    70-99 🏃 평균
    40-69 🐢 느림
    40 미만 🪨 매우 느림

    Step 1: 타입별 평균 스피드 분석

    pandas의 groupby로 모든 타입의 평균 스피드를 계산해봅시다!

    pandas groupby 문법

    # 타입별 평균 스피드
df.groupby('type1')['speed'].mean()

# 정렬하기
.sort_values(ascending=False)  # 내림차순

# 여러 통계 한번에
df.groupby('type1')['speed'].agg(['mean', 'min', 'max'])

    Step 2: seaborn barplot으로 타입별 비교 📊

    seaborn의 barplot은 평균과 신뢰구간을 자동으로 계산해줘요!

    seaborn barplot vs matplotlib bar

    # matplotlib (직접 계산 필요)
means = df.groupby('type1')['speed'].mean()
plt.bar(means.index, means.values)

# seaborn (한 줄로 끝!)
sns.barplot(data=df, x='type1', y='speed')

# seaborn 장점:
# - 자동으로 평균 계산
# - 에러바(신뢰구간) 자동 추가
# - order로 정렬 가능

    Step 3: seaborn boxplot으로 분포 비교 📦

    평균만 보면 놓치는 것이 있어요. 전체 분포를 봅시다!

    seaborn boxplot 문법

    # 기본 boxplot
sns.boxplot(data=df, x='type1', y='speed')

# 정렬 순서 지정
sns.boxplot(data=df, x='type1', y='speed', order=['fire', 'water', 'grass'])

# 색상 팔레트 변경
sns.boxplot(data=df, x='type1', y='speed', palette='coolwarm')

    박스플롯 읽는 법

    📦 박스플롯 해석

         ◇ ← 이상치 (outlier)
     ┬ ← 최댓값 (수염 끝)
     │
   ┌─┴─┐
   │   │ ← 상위 25% (3사분위)
   │───│ ← 중앙값 (50% 지점)
   │   │ ← 하위 25% (1사분위)
   └─┬─┘
     │
     ┴ ← 최솟값 (수염 끝)
    • 박스가 위에 있으면: 전체적으로 빠른 타입
    • 박스가 아래에 있으면: 전체적으로 느린 타입
    • 박스가 길면: 스피드 편차가 큼 (다양함)
    • 박스가 짧으면: 스피드 편차가 작음 (일정함)

    Step 6: 상관관계 히트맵 🔥

    seaborn의 heatmap으로 스피드와 다른 스탯의 관계를 한눈에!

    seaborn heatmap 문법

    # 상관관계 계산
corr = df[['speed', 'attack', 'defense']].corr()

# 히트맵으로 시각화
sns.heatmap(corr, annot=True, cmap='coolwarm')

# 옵션 설명
# annot=True: 숫자 표시
# cmap: 색상 팔레트
# center=0: 0을 기준으로 색상 대칭

    🎯 이번 레슨 요약

    배운 내용

    • [x] sns.barplot() - 자동 평균 + 에러바
    • [x] sns.boxplot() - 분포 비교
    • [x] sns.violinplot() - 더 자세한 분포
    • [x] sns.heatmap() - 상관관계 시각화
    • [x] order 파라미터로 정렬

    seaborn 핵심 문법 복습

    # 그룹별 평균 막대 그래프
sns.barplot(data=df, x='type1', y='speed', order=type_order)

# 박스플롯
sns.boxplot(data=df, x='type1', y='speed')

# 바이올린 플롯
sns.violinplot(data=df, x='type1', y='speed', inner='box')

# 히트맵
sns.heatmap(df.corr(), annot=True, cmap='coolwarm')
