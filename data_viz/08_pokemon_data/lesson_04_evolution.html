    미스터리 🔍

    무엇을 조사할까요?

    "진화하면 얼마나 강해질까요?"

    • 🐛 애벌레 → 🦋 나비: 엄청 변할 것 같아요
    • 🔥 파이리 → 리자드 → 리자몽: 점점 강해질까요?
    • 🐟 잉어킹 → 갸라도스: 정말 대폭 성장할까요?

    데이터로 확인해봅시다!

    배경 지식: 포켓몬 진화

    🔄 진화란?

    포켓몬이 레벨업하거나 특정 조건을 만족하면 더 강한 형태로 변해요!

    진화 단계 특징
    1단계 (기본) 가장 약함, 귀여움
    2단계 (중간) 중간 강함
    3단계 (최종) 가장 강함, 멋있음

    Step 1: 스타터 포켓몬 진화 분석 - lineplot

    seaborn lineplot으로 1세대 스타터 포켓몬의 진화를 분석해봅시다!

    seaborn lineplot

    # lineplot은 선 그래프에 최적화!
sns.lineplot(
    data=df, x='Stage', y='Base Total',
    hue='Type',      # 색상으로 타입 구분
    style='Type',    # 마커 스타일도 구분
    markers=True,    # 점 표시
    linewidth=3      # 선 굵기
)

    Step 2: 스탯별 성장 분석 - pointplot 📈

    리자몽 라인의 개별 스탯 성장을 분석해봅시다!

    seaborn pointplot

    # pointplot = 점 + 선 + 에러바
sns.pointplot(
    data=df, x='Pokemon', y='Value',
    hue='Stat',        # 스탯별로 다른 색
    markers=['o','s'], # 다양한 마커
    linestyles=['-','--']  # 선 스타일
)

# 에러바가 자동으로 추가돼요!

    Step 3: 가장 극적인 진화 찾기 - barplot 🚀

    800마리 중 진화 시 가장 큰 성장을 보이는 포켓몬은?

    Step 4: 잉어킹의 기적 - 그룹 barplot 🐟→🐉

    가장 유명한 극적인 진화! 잉어킹 → 갸라도스를 자세히 분석해봅시다.

    seaborn 그룹 비교

    # hue로 그룹 비교 barplot
sns.barplot(
    data=df, x='Stat', y='Value',
    hue='Pokemon',  # 포켓몬별로 다른 색
    palette={'Magikarp': 'pink', 'Gyarados': 'blue'}
)

    Step 5: 이브이 분기 진화 비교 - catplot 🌈

    하나의 포켓몬이 여러 형태로 진화하는 분기 진화를 분석해봅시다!

    seaborn heatmap으로 스탯 비교

    # 히트맵 = 색상으로 값을 표현
sns.heatmap(
    data,
    annot=True,    # 숫자 표시
    fmt='d',       # 정수 형식
    cmap='YlOrRd'  # 색상 맵 (노랑→빨강)
)
