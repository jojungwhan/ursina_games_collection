    🎯 학습 목표

    이 강의를 마치면 다음을 할 수 있어요:

    • ○ 딕셔너리로 DataFrame을 만들 수 있다
    • ○ DataFrame의 기본 정보를 확인할 수 있다
    • ○ 특정 열(column)을 선택할 수 있다

    DataFrame 만들기

    방법 1: 딕셔너리로 만들기

    가장 많이 사용하는 방법이에요!

    딕셔너리 → DataFrame 구조

    {
    "열 이름1": [값1, 값2, 값3],
    "열 이름2": [값1, 값2, 값3],
    ...
}
    - 키(key) = 열 이름 (column name) - 값(value) = 해당 열의 데이터 리스트

    방법 2: 리스트의 리스트로 만들기

    import pandas as pd

# 리스트의 리스트
data = [
    ["피카츄", "전기", 35],
    ["파이리", "불꽃", 39],
    ["꼬부기", "물", 44]
]

# 열 이름을 따로 지정
df = pd.DataFrame(data, columns=["이름", "타입", "HP"])
print(df)

    DataFrame 기본 정보 확인

    기본 정보 함수 정리

    함수/속성 설명 예시 출력
    df.shape (행 수, 열 수) (5, 4)
    df.columns 열 이름들 Index(['이름', '타입', 'HP', ...])
    df.dtypes 각 열의 데이터 타입 이름: object, HP: int64
    len(df) 행 수 5

    데이터 미리보기

    head()와 tail()

    언제 사용하나요?

    • head(): 데이터가 어떻게 생겼는지 미리보기할 때
    • tail(): 마지막 데이터를 확인할 때
    • 데이터가 수천 개일 때 전체를 출력하면 너무 길어요!

    💻 연습: head()와 tail() 사용하기

    🎯 퀴즈

    퀴즈: DataFrame 열 선택
    DataFrame에서 '이름'과 'HP' 두 열을 동시에 선택하려면?
    정답 보기

    정답: B) df[['이름', 'HP']]

    여러 열을 선택할 때는 대괄호를 두 번 사용해요! 안쪽 대괄호는 열 이름들의 리스트를 만들고, 바깥쪽 대괄호는 그 리스트로 선택하는 것이에요.

    퀴즈: DataFrame 크기
    df.shape가 (100, 5)라면 이 데이터는?
    정답 보기

    정답: A) 100개의 행과 5개의 열

    shape는 항상 (행, 열) 순서예요! - 첫 번째 숫자 (100) = 행(row) 수 = 데이터 개수 - 두 번째 숫자 (5) = 열(column) 수 = 항목 수

    DataFrame 기초 빈칸 채우기:

    포켓몬 데이터 df가 있을 때:

    • 데이터의 처음 5행만 미리보기: df. ()
    • 데이터의 마지막 5행만 보기: df. ()
    • 데이터의 (행 수, 열 수) 확인: df.
    • 'name' 열만 선택하기: df[ ]
