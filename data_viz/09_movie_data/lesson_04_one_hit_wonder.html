    4. 🎰 원히트원더

    ← 효율왕 ⏱️ 15분 코스 홈 →

    🎯 학습 목표

    • 비율(Ratio)과 백분율(Percentage) 계산하기
    • 의존도(Dependency) 분석하기
    • 한 작품에 의존하는 브랜드 찾기
    • 리스크 분산의 중요성 이해하기

    미스터리 🔍

    무엇을 조사할까요?

    어떤 브랜드가 한 작품에 너무 의존하고 있을까?

    예를 들어: - 총 수익 $10B 중 $5B가 단 한 편에서 나온다면? - 그 한 편이 50%를 책임지는 것!

    이런 브랜드는 원히트원더일 수 있어요. 다음 히트작이 없으면 위험할 수 있죠!

    배경 지식: 비율과 백분율

    📊 비율(Ratio)과 백분율(Percentage)

    비율: 전체 중에서 부분이 차지하는 양

    # 의존도 계산
dependency = top_movie_revenue / total_revenue

# 백분율로 변환 (0~100%)
dependency_percent = (top_movie_revenue / total_revenue) * 100

    예시:

    브랜드 총 수익 1위 작품 수익 의존도
    A 브랜드 $10B $5B 50%
    B 브랜드 $10B $1B 10%

    A는 원히트원더, B는 안정적!

    Step 1: 의존도 컬럼 만들기 📊

    Dependency 컬럼을 만들어봅시다!

    백분율 계산 코드

    # 백분율 계산
df['Percentage'] = (df['Part'] / df['Total']) * 100

# 의존도 계산
df['Dependency'] = (df['Lifetime Gross'] / df['Total']) * 100

# 해석
# 50% → 총 수익의 절반이 한 작품에서
# 10% → 수익이 고르게 분산됨

    Step 2: TOP 5 원히트원더 찾기 🎰

    의존도가 가장 높은 브랜드를 찾아봅시다!

    Step 3: 의존도 시각화 📊

    seaborn barplot으로 의존도를 시각화해봅시다!

    seaborn barplot 색상 지정

    # 조건에 따른 색상 리스트
colors = ['red' if d > 50 else 'orange' if d > 30 else 'green'
          for d in df['Dependency']]

# barplot에 palette로 전달
sns.barplot(data=df, y='Brand', x='Dependency',
            hue='Brand', palette=colors, legend=False)

    Step 4: 안정적인 브랜드 vs 원히트원더 🎭

    가장 안정적인 브랜드와 원히트원더를 비교해봅시다!

    seaborn 컬러 팔레트

    # 내장 팔레트 (뒤에 _d 붙이면 진한 버전)
palette='Blues_d'    # 파란 계열
palette='Greens_d'   # 초록 계열
palette='Reds_d'     # 빨간 계열
palette='Oranges_d'  # 주황 계열
palette='Purples_d'  # 보라 계열

# 기타 유용한 팔레트
palette='husl'       # 무지개 색
palette='Set2'       # 부드러운 색상
palette='viridis'    # 청록-노랑 그라데이션

    차트 해석: 리스크 분산 🎯

    중요한 인사이트

    안정적인 브랜드의 특징:

    브랜드 의존도 영화 수 특징
    Marvel Comics ~5% 69편 다양한 히트작 보유
    Blumhouse ~7% 49편 저예산 다작 전략
    Stephen King ~19% 49편 꾸준한 원작 공급

    원히트원더의 위험:

    • 한 작품이 실패하면 전체 수익 급감
    • 후속작 압박이 큼
    • 브랜드 지속 가능성 낮음

    Step 5: 의존도 히스토그램 📈

    전체 브랜드의 의존도 분포를 살펴봅시다!

    seaborn histplot + 배경 영역

    # 배경 영역 색칠 (matplotlib 함수)
plt.axvspan(0, 30, alpha=0.15, color='green')   # x=0~30 영역

# 히스토그램 + KDE
sns.histplot(data=df, x='Dependency', bins=12, kde=True)

# 수직선 추가
plt.axvline(x=30, color='green', linestyle='--')
plt.axvline(x=50, color='red', linestyle='--')

    🧠 퀴즈 타임!

    생각해보세요

    "로알 달(Roald Dahl) 브랜드의 의존도가 약 58%예요. 이 브랜드가 '찰리와 초콜릿 공장' 외에 다른 히트작을 만들어야 하는 이유는 무엇일까요?"

    힌트 보기

    리스크 관리의 관점에서 생각해보세요!

    현재 상황: - 전체 수익의 58%가 '찰리와 초콜릿 공장'에서 - 나머지 42%가 다른 모든 영화에서

    위험 요소: 1. 후속작이 실패하면 수익 급감 2. 한 작품의 인기가 식으면 브랜드 가치 하락 3. 새로운 팬층 확보 어려움

    해결책: - '마틸다', 'BFG' 같은 다른 원작 영화화 - 다양한 히트작으로 포트폴리오 분산 - 마블처럼 여러 작품이 고르게 수익 창출

    📚 이번 수업에서 배운 것

    핵심 정리

    비율과 백분율 계산: 

    # 비율 (0~1 사이 값)
ratio = part / total

# 백분율 (0~100% 사이 값)
percentage = (part / total) * 100

# 의존도 계산
df['Dependency'] = (df['Lifetime Gross'] / df['Total']) * 100

    seaborn 시각화: 

    # 가로 막대 그래프
sns.barplot(data=df, y='Brand', x='Dependency', orient='h')

# 히스토그램 + KDE + 영역 색칠
plt.axvspan(0, 30, alpha=0.15, color='green')  # 배경 영역
sns.histplot(data=df, x='Dependency', kde=True)
plt.axvline(x=30, linestyle='--')  # 경계선

    의존도 해석:

    의존도 의미 상태
    0-30% 수익이 고르게 분산됨 🟢 안정
    30-50% 한 작품 비중이 큼 🟡 주의
    50%+ 한 작품에 과도하게 의존 🔴 위험
