    🎯 학습 목표

    • Feature Engineering: 새로운 컬럼 만들기
    • 평균(Mean) 개념으로 효율성 계산하기
    • 총액과 평균의 차이 이해하기
    • 데이터에서 숨겨진 인사이트 발견하기

    미스터리 🔍

    무엇을 조사할까요?

    마블이 총 수익 1위인데... 영화 한 편당 수익도 1위일까?

    • 🦸 마블: 총 $15.8B를 벌었지만 69편이나 만들었어요
    • 🏰 픽사: 총 $6.1B를 벌었지만 28편만 만들었어요

    영화 한 편당 수익으로 비교하면 누가 이길까요?

    배경 지식: Feature Engineering

    🔧 Feature Engineering (파생 변수 만들기)

    기존 데이터로 새로운 컬럼을 계산해서 만드는 것!

    # 영화 한 편당 평균 수익 계산
df['Average_Gross'] = df['Total'] / df['Releases']

    예시:

    브랜드 Total Releases Average (계산)
    Marvel $15.8B 69편 $229M/편
    Pixar $6.1B 28편 $217M/편

    왜 필요할까?

    • 원본 데이터에 없는 새로운 인사이트 발견
    • 공정한 비교 가능 (영화 수가 다른 브랜드 비교)
    • 데이터 분석의 핵심 스킬!

    Step 1: 평균 수익 컬럼 만들기 📊

    새로운 컬럼 Average_Gross를 만들어봅시다!

    Feature Engineering 코드 설명

    # 새로운 컬럼 만들기
df['새컬럼'] = df['컬럼A'] / df['컬럼B']

# 계산 연산자
# +  더하기
# -  빼기
# *  곱하기
# /  나누기

# 예시
df['Average'] = df['Total'] / df['Releases']
df['Profit'] = df['Revenue'] - df['Cost']
df['Rate'] = df['Hits'] / df['Attempts'] * 100

    Step 2: TOP 5 효율왕 찾기 🏆

    영화 한 편당 수익 기준 TOP 5를 찾아봅시다!

    seaborn barplot 설명

    # seaborn 막대 그래프
sns.barplot(data=df, x='Brand', y='Average_M',
            hue='Brand', palette=colors)

# 주요 파라미터
# data: DataFrame
# x, y: 축에 매핑할 컬럼
# hue: 색상 그룹 (같은 컬럼이면 막대별 색상)
# palette: 색상 리스트 또는 팔레트 이름
# order: 막대 순서 지정

    놀라운 발견! 😲

    효율왕 분석 결과

    마블은 총액 1위이지만 효율(편당 수익)은 TOP 5에 없을 수도 있어요!

    효율왕 후보들:

    브랜드 편당 수익 특징
    🏆 Walt Disney Animation ~$185M 겨울왕국, 주토피아 대박
    🥈 Pixar ~$217M 모든 영화가 고퀄리티
    🥉 Illumination ~$212M 미니언즈의 힘!
    📍 Bad Robot ~$205M J.J. 에이브럼스 스튜디오
    📍 Lucasfilm ~$162M 스타워즈 파워

    Step 3: 효율 vs 총액 비교 📊

    총액 TOP 10과 효율 TOP 10이 얼마나 다른지 비교해봅시다!

    seaborn 가로 막대 그래프

    # 가로 막대 그래프 (orient='h')
sns.barplot(data=df, y='Brand', x='Value', orient='h')

# 또는 x, y 위치만 바꾸면 됨
sns.barplot(data=df, x='Value', y='Brand')

# 순서 지정하려면 order 파라미터
order = df.sort_values('Value', ascending=False)['Brand']
sns.barplot(data=df, y='Brand', x='Value', order=order)

    Step 4: 모든 브랜드 효율 분석 📈

    전체 브랜드의 효율 분포를 히스토그램으로 살펴봅시다!

    seaborn histplot 설명

    # 히스토그램 + KDE (밀도 곡선)
sns.histplot(data=df, x='Average_M', bins=15, kde=True)

# 주요 파라미터
# bins: 막대 개수
# kde: True면 밀도 곡선 추가
# color: 막대 색상
# alpha: 투명도
# line_kws: KDE 선 스타일 (딕셔너리)

# KDE만 그리기
sns.kdeplot(data=df, x='Average_M', fill=True)

    🧠 퀴즈 타임!

    생각해보세요

    "마블은 69편의 영화를 만들었고, 픽사는 28편만 만들었어요. 하지만 효율에서 픽사가 더 높을 수 있어요. 이게 의미하는 바는 무엇일까요?"

    힌트 보기

    양 vs 질의 전략 차이!

    마블 전략 (양 전략): - 많은 영화를 만들어서 총 수익 극대화 - 일부 실패작이 있어도 전체로 만회 - 캐릭터와 세계관 확장에 집중

    픽사 전략 (질 전략): - 적지만 완성도 높은 영화만 제작 - 모든 영화가 고퀄리티 보장 - 실패 리스크 최소화

    둘 다 성공한 전략이에요! 목표가 다를 뿐.

    📚 이번 수업에서 배운 것

    핵심 정리

    Feature Engineering: 

    # 새로운 컬럼 만들기
df['새컬럼'] = df['컬럼A'] / df['컬럼B']

# 실제 예시
df['Average_Gross'] = df['Total'] / df['Releases']
df['Efficiency'] = df['Revenue'] / df['Cost']
df['Success_Rate'] = df['Hits'] / df['Total'] * 100

    seaborn 시각화: 

    # 막대 그래프
sns.barplot(data=df, x='Brand', y='Value', hue='Brand')

# 히스토그램 + KDE
sns.histplot(data=df, x='Value', bins=15, kde=True)

    인사이트:

    • 총액 1위 ≠ 효율 1위
    • 데이터를 다른 각도로 보면 새로운 발견!
    • Feature Engineering = 숨겨진 인사이트 찾기
