    미스터리 🔍

    무엇을 조사할까요?

    영화를 많이 만들면 돈도 많이 벌까?

    직관적으로는 "당연히 그렇지!"라고 생각할 수 있지만...

    • 🎬 양 전략: 영화를 많이 만들어서 수익 늘리기
    • 🎯 질 전략: 적은 영화로 대박 터뜨리기

    어떤 전략이 더 효과적일까요?

    배경 지식: 산점도와 상관관계

    📊 산점도 (Scatter Plot)

    두 개의 숫자 데이터 관계를 점으로 표시하는 그래프예요!

    높음 ┃  ⭐          ← 적게 만들고 많이 번다 (효율왕)
총   ┃     ●
수   ┃  ●    ●  ⭐ ← 많이 만들고 많이 번다 (성실왕)
익   ┃    ●  ●
     ┃ ●  ●        ← 많이 만들고 적게 번다 (노력왕)
낮음 ┗━━━━━━━━━━━━━━━━
       적음  영화 수  많음

    상관관계 유형:

    유형 패턴 의미
    양의 상관 ↗️ 우상향 하나가 증가하면 다른 것도 증가
    음의 상관 ↘️ 우하향 하나가 증가하면 다른 것은 감소
    무상관 🔀 흩어짐 관계 없음

    Step 1: 전체 브랜드 산점도 - scatterplot 📊

    seaborn scatterplot으로 영화 수(Releases)와 총 수익(Total)의 관계를 살펴봅시다!

    seaborn scatterplot

    # scatterplot - 한 줄로 산점도!
sns.scatterplot(data=df, x='Releases', y='Total_B', s=150, alpha=0.6)

# s=150 : 점 크기
# alpha=0.6 : 투명도

# 상관계수 계산
df['A'].corr(df['B'])

    Step 2: 추세선이 있는 산점도 - regplot 📈

    regplot을 사용하면 자동으로 추세선(회귀선)을 그려줍니다!

    seaborn regplot

    # regplot = scatter + 회귀선
sns.regplot(data=df, x='Releases', y='Total_B')

# 자동으로:
# - 산점도 그리기
# - 추세선(회귀선) 계산
# - 신뢰구간 표시

# 점과 선 스타일 커스터마이징
sns.regplot(data=df, x='x', y='y',
            scatter_kws={'s': 100},      # 점 스타일
            line_kws={'color': 'red'})   # 선 스타일

    Step 3: 영역별 색상 산점도 🎨

    4가지 영역을 hue로 구분해서 시각화해봅시다!

    seaborn hue와 style

    # hue = 색상으로 그룹 구분
# style = 마커 모양으로도 구분
sns.scatterplot(
    data=df, x='Releases', y='Total_B',
    hue='Category',   # 카테고리별 색상
    style='Category', # 카테고리별 마커
    s=200             # 점 크기
)

    Step 4: jointplot으로 분포 함께 보기 📊

    산점도와 함께 각 변수의 분포(히스토그램)도 볼 수 있어요!

    seaborn jointplot

    # jointplot = 산점도 + 양쪽 분포
sns.jointplot(data=df, x='Releases', y='Total_B', kind='reg')

# kind 옵션:
# 'scatter': 단순 산점도
# 'reg': 회귀선 포함
# 'hex': 육각형 밀도
# 'kde': 등고선 밀도

    🧠 퀴즈 타임!

    생각해보세요

    "픽사와 일루미네이션(미니언즈)은 영화 수가 적은데도 TOP 10에 들어있어요. 이 두 브랜드의 공통점은 무엇일까요?"

    힌트 보기

    두 브랜드 모두 애니메이션 전문 스튜디오예요!

    • 픽사: 토이스토리, 니모를 찾아서, 인사이드아웃
    • 일루미네이션: 미니언즈, 슈퍼배드, 싱

    애니메이션 영화는: 1. 제작 시간이 오래 걸려서 영화 수가 적음 2. 하지만 가족 관객층을 확보해 꾸준히 흥행 3. 캐릭터 굿즈, 테마파크 등 부가수익도 큼!

    결론: 적게 만들어도 확실하게 성공!

    📚 이번 수업에서 배운 것

    핵심 정리

    seaborn 산점도: 

    # 기본 산점도
sns.scatterplot(data=df, x='x', y='y', hue='category')

# 추세선 포함
sns.regplot(data=df, x='x', y='y')

# 산점도 + 분포
sns.jointplot(data=df, x='x', y='y', kind='reg')

    상관계수: 

    df['A'].corr(df['B'])  # -1 ~ +1

# +1: 강한 양의 상관
# 0: 상관없음
# -1: 강한 음의 상관

    이상치 (Outlier):

    • 다른 데이터와 동떨어진 극단적인 값
    • 분석을 왜곡할 수 있음
    • 제외하고 분석하면 다른 패턴이 보일 수 있음
