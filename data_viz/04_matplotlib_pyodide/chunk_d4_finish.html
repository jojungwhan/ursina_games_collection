    서브플롯 - 4개 그래프 한 화면에

    서브플롯으로 여러 그래프를 배치해보세요!

    영역 그래프 (Area Chart)

    시간에 따른 누적 데이터를 영역 그래프로 표현해보세요!

    ⚠️ 실수해보기 (Let's Break It!)

    다음 코드에는 오류가 있어요. 무엇이 잘못되었을까요?

    import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2)

# 첫 번째 서브플롯에 그래프 그리기
axes[0].plot([1, 2, 3], [1, 4, 9])  # 오류 발생!
plt.show()
    힌트 보기

    subplots(2, 2)는 2x2 배열을 만듭니다. 2차원 배열은 어떻게 접근할까요?

    정답 보기

    2x2 서브플롯은 axes[행, 열]로 접근해야 합니다!

    import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2)

# 올바른 접근: [행, 열]
axes[0, 0].plot([1, 2, 3], [1, 4, 9])  # 1행 1열
axes[0, 1].bar([1, 2, 3], [3, 5, 2])   # 1행 2열
axes[1, 0].scatter([1, 2, 3], [2, 3, 1])  # 2행 1열
axes[1, 1].hist([1, 2, 2, 3, 3, 3])    # 2행 2열

plt.tight_layout()
plt.show()
    배치 접근 방법
    1x3 (1행) axes[0], axes[1], axes[2]
    2x2 (2행) axes[0,0], axes[0,1], axes[1,0], axes[1,1]

    빈칸 채우기 연습

    다양한 그래프 연습:

    • 원 그래프: plt. (values, labels=labels)
    • 퍼센트 표시: autopct=
    • 서브플롯 생성: fig, axes = plt. (2, 2)
    • 레이아웃 자동 조정: plt. ()

    🎯 빈칸 채우기 미션

    빈칸을 채워서 코드를 완성하세요!

    정답 확인 
    fig, axes = plt.subplots(2, 2)
axes[0, 0].plot([1, 2, 3], [1, 4, 9])
    정답 확인 
    plt.stackplot(months, game, study, labels=['Game', 'Study'])

    🎯 퀴즈

    퀴즈: 서브플롯 이해
    `plt.subplots(2, 3)`을 실행하면 몇 개의 그래프 영역이 생성될까요?
    정답 보기

    정답: B) 6개 (2×3)

    subplots(rows, cols)는 행 × 열 만큼의 그래프 영역을 만듭니다!

    [0,0] [0,1] [0,2]
[1,0] [1,1] [1,2]

    2행 3열 = 6개의 서브플롯이 생성됩니다.
