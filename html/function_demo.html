함수(Function) 변환기

입력을 넣으면 규칙에 따라 출력이 나오는 '마법 상자'를 체험해보세요.

INPUT (입력)
FUNCTION (규칙)
변환 규칙 (Rule)
f(x) = x + 3
OUTPUT (출력)
-
Data
📐 수학에서의 함수

규칙: 들어온 숫자에 무조건 3을 더하는 규칙입니다.
2를 넣으면 5가 나오고, 10을 넣으면 13이 나옵니다. 이 규칙은 절대 변하지 않습니다.

💻 코딩에서의 함수: shape() 예시

함수 호출: t.shape('turtle')
- 입력: 문자열 'turtle'
- 규칙: shape() 함수가 모양을 변경
- 출력: 화면에 거북이 모양이 나타남

중요: 문자열은 반드시 따옴표로 감싸야 합니다!
✅ t.shape('turtle') | ❌ t.shape(turtle)

사용 가능한 모양: 'turtle', 'arrow', 'circle', 'square', 'triangle'
