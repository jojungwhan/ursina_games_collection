    코드 살펴보기

    아래는 모든 기능을 보여주는 예제 코드입니다.

    📂 폴더: example / 📄 파일: example.py

    example.py
    from ursina import *  # (1)
import os  # (2)

app = Ursina()  # (3)

# 설정
window.color = color.black  # (4)

# 기본 Entity 생성
my_entity = Entity(  # (5)
    model='cube',
    color=color.yellow,
    scale=2
)

EditorCamera()  # (6)
app.run()  # (7)
    1. Ursina 라이브러리의 모든 기능을 가져옵니다
    2. os 모듈을 불러옵니다
    3. 게임 창을 만들어 app 변수에 저장합니다
    4. 창 배경색을 검은색으로 설정합니다
    5. 노란색 큐브를 만들어 my_entity 변수에 저장합니다
    6. 마우스로 화면을 돌려볼 수 있는 카메라를 만듭니다
    7. 게임을 실행합니다
    ⚡ 실행 방법이 기억나지 않나요? (클릭)
    • 터미널 이동: cd .. 후 cd 폴더명
    • 실행: python 파일이름.py (Tab 키로 자동완성)
    • 종료: Alt+F4 (Win) / Cmd+Q (Mac)

    💡 기능별 예제

    라이브러리 불러오기 (Import Statements)

    위의 코드 (1)번과 (2)번을 보면:

    from ursina import *
import os

    핵심 개념: - (1) Ursina 엔진의 모든 기능을 불러옵니다 - (2) os 모듈을 불러옵니다

    라이브러리 불러오기 복습:

    코드를 작성하려면 먼저 라이브러리를 불러와야 합니다.

    • `from ursina import ` - Ursina의 모든 기능을 가져옵니다
    • `import ` - 운영체제 관련 기능을 사용하기 위해 필요합니다

    Entity 생성하기

    코드 (5)번에서 Entity를 만듭니다:

    my_entity = Entity(
    model='cube',
    color=color.yellow,
    scale=2
)

    설명: - Entity(...): 새로운 Entity가 태어납니다! 🧊 - model='cube': 큐브 모양으로 만들기 - color=color.yellow: 노란색으로 만들기 - scale=2: 크기를 2배로 만들기

    📦 변수를 사용하는 이유

    변수에 저장하면 나중에 my_entity.color = color.red처럼 다시 사용할 수 있습니다!

    Entity 만들기:

    Entity를 만들고 변수에 저장하는 방법을 배워봅시다.

    {{blank:my_entity|hint=변수 이름}} = Entity(
    model={{blank:'cube'|hint=모양}},
    color={{blank:color.yellow|case=insensitive|hint=색상}},
    scale={{blank:2|hint=크기}}
)
    • `` - 변수 이름 (나중에 사용하기 위해 저장)
    • `model=` - 큐브 모양으로 만들기
    • 변수에 저장하면 나중에 `.color = color.red`처럼 사용할 수 있습니다

    번호 목록

    Entity의 주요 인자들:

    1. model - 모양 결정
    2. color - 색상 결정
    3. texture - 표면 무늬
    4. scale - 크기 조절
    5. position - 위치 결정

    불릿 목록

    Entity를 만들 때 사용할 수 있는 모양들:

    • 'cube' - 큐브 🧊
    • 'sphere' - 구 ⚪
    • 'plane' - 평면 📄
    • 'quad' - 사각형 ⬜

    📊 테이블 예제

    Entity의 주요 인자들을 정리한 표입니다:

    인자 설명 시각적 변화 예시
    model 모양 결정 🧊 큐브 → ⚪ 구 → 📄 평면 'cube', 'sphere', 'plane'
    color 색상 결정 🔴 빨강 → 🔵 파랑 → 🟡 노랑 color.red, color.blue
    texture 표면 무늬 적용 단색 → 🌿 잔디 → 🧱 벽돌 'white_cube', 'grass'
    scale 크기 결정 작은 큐브 → 큰 큐브 1, 2, (2, 1, 3)
    position 위치 결정 왼쪽 → 오른쪽 → 위쪽 (0, 0, 0), (1, 2, 3)
    alpha 투명도 결정 선명함 → 반투명 → 거의 안 보임 1.0 (불투명), 0.1 (투명)

    🎨 model, color, texture의 차이

    많은 학생들이 헷갈려하는 부분입니다:

    • model: 모양 자체를 바꿉니다 🧊 → ⚪
    • color: 색상만 바꿉니다 🔴 → 🔵
    • texture: 표면의 그림을 입힙니다 🎨

    Entity에서 어떤 인자가 모양(shape)을 바꾸나요?
    정답 보기

    정답: A) model

    model 인자가 Entity의 모양(shape)을 결정합니다.

    코드에서 확인해보세요: 

    Entity(model='cube')    # 큐브 모양
Entity(model='sphere')  # 구 모양
Entity(model='plane')   # 평면 모양

    퀴즈 2: 변수 할당하기

    퀴즈: 변수 할당하기
    코드에서 Entity를 저장한 변수 이름은 무엇인가요?
    힌트: ??? = Entity(model='cube', color=color.yellow, ...)
    정답 보기

    정답: my_entity

    코드에서 확인해보세요: 

    my_entity = Entity(
    model='cube',
    color=color.yellow,
    scale=2
)

    ⚠️ 자주 하는 실수
    

    학생들이 자주 실수하는 부분과 해결 방법입니다.
    

    실수 1: 인자 형식 오류
    

    # ❌ 잘못된 코드
Entity(model:cube)        # : 대신 = 사용해야 함
Entity(model-'cube')      # - 대신 = 사용해야 함

    

    증상: SyntaxError: invalid syntax
    
해결: 인자는 이름=값 형식으로 작성하세요
    

    # ✅ 올바른 코드
Entity(model='cube')
Entity(model='cube', color=color.red)

    

    

    자주 하는 실수 복습:
    

    

    다음 코드에서 실수를 찾아 빈칸을 채워보세요!
    

    실수 1: 인자 형식 오류

    # ❌ 잘못된 코드
Entity(model{{blank::|hint=잘못된 기호}}cube)  # : 대신 = 사용해야 함

# ✅ 올바른 코드
Entity(model{{blank:=|hint=올바른 기호}}'cube')
